# Sales Performance Dashboard | Power BI

An interactive sales analytics dashboard built in Power BI, analyzing retail sales, profit, and regional performance using the Superstore dataset.

## Overview
This dashboard turns raw retail transaction data into actionable business insights. It tracks revenue, profit, and order trends across time, product categories, regions, and customer segments, with interactive filtering.

## Key Metrics (KPIs)
- Total Revenue, Total Profit, Profit Margin %
- Total Orders, Average Order Value, Total Quantity

## Visualizations
- **Revenue Trend by Year** — line chart showing sales growth over time
- **Revenue by Sub-Category** — treemap of top-performing product groups
- **Top 10 Products by Revenue** — ranked table with revenue and profit
- **Profit by Segment** — donut chart (Consumer / Corporate / Home Office)
- **Revenue by Region** — bar chart across West, East, Central, South
- **Interactive slicers** — filter the entire dashboard by Year, Region, and Category

## Tools & Techniques
- **Power BI Desktop** — data modeling, visualization, dashboard design
- **DAX** — custom measures (Total Revenue, Profit Margin %, Avg Order Value, etc.)
- **Power Query** — data cleaning, type/locale correction, date handling
- **Data source:** Superstore dataset (Kaggle)
